# 002 负荷迁移表结构

应用启动时为连续三周负荷迁移看板补建以下新表，既有表结构不变。

- `week_snapshots` 按（统计周， 修订号）唯一保存不可变周数据；更正乱序到达时按修订号取最新，旧修订只存档。
- `migration_board` 单行看板状态：三周窗口、计算参数、单调递增的触发代际号，以及当前发布指针与已发布修订号。
- `migration_reports` 两段迁移的计算任务与结果版本，带运行租约和尝试次数；发布时以代际号与三周修订号做守卫，按较早修订算出的结果不顶掉新版。
- `shift_suggestions` 已发出的补班建议，以 JSON 快照保存发出时的迁移依据（报告版本、各周修订、原群与去向、迁移类别、参数）。
